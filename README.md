# José Gerardo Ferreccio Riega — Portfolio

Portfolio profesional de José Gerardo Ferreccio Riega, **Digital Media & SEO Specialist**.

El sitio presenta experiencia, casos de estudio, competencias y herramientas en estrategia digital, SEO, Content Marketing, Social Media, Performance Marketing, analítica digital y comunicación.

## Stack

- Astro
- Tailwind CSS
- TypeScript
- GitHub Actions
- GitHub Pages

## Secciones

- Inicio
- Proyectos / casos de estudio
- Skills & Tools
- Experiencia
- Sobre mí
- CV profesional
- Contacto

## Desarrollo local

```bash
pnpm install
pnpm dev
```

Para generar la versión de producción:

```bash
pnpm build
```

## Deploy

Cada push a `main` ejecuta el workflow de GitHub Actions y publica el sitio en GitHub Pages.
